Retro Roleplay Anti-Cheat nasıl çalışır?

Yetkili panelden tek tıkla 4 haneli PIN üretir. Şüpheli oyuncu RetroAC_Scanner.exe uygulamasını açıp bu PIN kodunu girer ve ACCESS butonuna basar. Yaklaşık 3.8 saniyelik derin adli analiz motoru; çalışan süreçleri, açık makro pencerelerini, oyun DLL modüllerini, Windows BAM silinmiş program geçmişini ve Prefetch önbelleğini tarayarak raporu anında bu web paneline iletir.

Oyuncu kontrol öncesi hileyi silerse yakalanır mı?

Kesinlikle evet! Windows BAM (Background Activity Moderator) ve Prefetch mekanizmaları sayesinde, oyuncu hile dosyasını veya klasörünü silmiş olsa dahi Windows kayıt defterinde saklanan adli çalıştırma damgaları ve zaman kayıtları tespit edilir.

Makro ve Sekmeme araçları nasıl tespit edilir?

Sistem; AutoHotkey, TinyTask, OP AutoClicker gibi süreçleri listelemekle kalmaz, oyuncu dosya adını svchost veya discord yapsa dahi Win32 pencere başlığı taramasıyla gizlenmiş makroları bulur. Ayrıca Downloads ve Masaüstündeki .ahk dosyalarının kodlarını inceleyerek seri tıklama döngülerini yakalar.

Web paneline farklı bilgisayarlardan nasıl bağlanılır?

Sunucu 0.0.0.0:3000 üzerinden dinler. Yerel ağınızdaki cihazlardan http://[SİZİN-IP]:3000 adresiyle erişebilirsiniz. İnternet üzerinden uzaktaki oyuncuları taramak için port açabilir veya ücretsiz ngrok http 3000 / Cloudflare Tunnel kullanarak herkese açık güvenli bir link oluşturabilirsiniz.
